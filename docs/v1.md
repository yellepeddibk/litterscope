# LitterScope V1

## Problem

The main problem with littering and exisiting solutions (similar apps) are that they don't specifically recommend what to do with the litter. They also don't have a feature for others to report if the litter was cleaned up or not.

Our intention is to use all information, type of litter, location, frequency of reports, and other variables to recommend actionable steps to mititgate littering.

## Target User

This applications audience incldues those who contribute to civil work and are interested in a cleaner environment. This includes ordinary citizens, volunteers, students, and city workers. 

Version 1 will not allow a user to create an account in order to report a litter incident. This is to encourage more users and prevent account creation from becoming a burden. This is subject to change in future versions.

## V1 Goal

An observation in an incident report is meant to represent an entire littered area; the varying litter types will be broken down in that area.

In V1, we want the user to be able to submit a photo along with the exact location they are at, and a small description. This is followed by a basic image analysis.

## User Stories

A User story, or an incident report, must include an image supplied by an optional description so that the system can analyze the littered area. 

GPS/location is also a mandatory requirement in order for the application to have a thorough analysis and provide actionable recommendations. User can manually choose location in in case GPS is unavailable or picture was captured previosuly. Regardless, a location must be submitted.

Reports may be edited after submission only by the user who created them within 24 hours.Must have an account to be edited. Regular submissions don't require an account.

Users may update other reports and "cleaned" if they observe so. In this case, they must also submit an image supplied by an optional description, which will then be cross-checked in the system to confirm. This does nto rremove or modify the original report, it simply acts as a tag or addition.

All observation are public.

As a user, I can:

- Report the litter 
- Clean up litter (If possible)
- Report if the incident was resolved

## Out of Scope

Recommendations will not be implemented in this version. This will be the actual decsision our ML algorithms will make based on the analysis. The focus for this version will remain to simply ensure Users can take images and upload them to the image file storage, and then run image analysis.

## Definition of Done

Version 1 is complete once the following requirements have been met:

- The app is running smoothly and all the features are working.
- The images are being uploaded to the image file storage properly.
- We need to make it testable by capturing images
